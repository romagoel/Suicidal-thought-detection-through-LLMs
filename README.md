# Suicidal-thought-detection-through-LLMs
This work was carried for the research paper titled "LLM Assisted Multiclass Classification of Synthetically Generated and Survey Data to Detect Depression and Identify Suicidal Thoughts".

Main objective of our research is to detect suicidal thoughts and depressive thoughts from various datasets.
This folder consistes of 3 files, named as  File 1.py, File 2.py and File 3.py.
This folder contains two datasets named as reddit_depression_suicidewatch.xls and Suicide_Detection.xls
